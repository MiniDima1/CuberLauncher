# CuberLauncher

CuberLauncher — удобный лаунчер для Minecraft. Он помогает запускать игру, устанавливать моды и управлять версиями без лишней возни.

## Возможности

- **Запуск любых версий Minecraft** — официальные, снапшоты и модифицированные сборки.  
- **Установка Forge и OptiFine** прямо из лаунчера.  
- **Автоматическая проверка и установка Java** при необходимости.  
- **Настройка памяти для игры**.  

## Как пользоваться

1. Выберите нужную версию Minecraft.  
2. Настройте выделение памяти (RAM), если нужно.  
3. Если требуется, скачайте Java через кнопку в лаунчере.  
4. Нажмите **«Запустить»**.

## Примечания

- Лаунчер сам заботится о том, чтобы все нужные файлы были на месте.  
- Просто запускайте и играйте — никаких лишних настроек!
