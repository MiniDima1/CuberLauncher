# CuberLauncher

**CuberLauncher — удобный лаунчер для Minecraft.**  
Поддерживает официальные версии, снапшоты и модифицированные версии (Forge, Fabric, Quilt).  
С ним легко управлять версиями Minecraft и быстро начать игру.

## Возможности

- **Запуск любых версий Minecraft** — официальные, снапшоты и модифицированные версии (Forge, Fabric, Quilt).  
- **Автоматическая проверка и установка Java**.  
- **Настройка памяти (RAM)** для оптимальной работы игры.  
- Удобный интерфейс для быстрого запуска.

## Как пользоваться

1. Выберите нужную версию Minecraft.  
2. Настройте выделение памяти при необходимости.  
3. Скачайте Java через меню лаунчера, если требуется.  
4. Нажмите **«Запустить»** и начинайте играть.

## Примечания

- Лаунчер самостоятельно заботится о необходимых игровых файлах.  
- Подходит для новичков и опытных игроков Minecraft.
